## Mandatory Sections
1. Document Control (version table)
2. Purpose (system description, V-model position)
3. System Context (boundary, context diagram in Mermaid, interface list)
4. StRS Reference (input document list)
5. System Requirements (organized by type, each as requirement_card_template)
6. Requirements Summary (pie chart + BP bar chart in Mermaid)
7. Traceability Matrix (from traceability_matrix_template)
8. Open Issues / Gaps
9. Review Records (BP7 evidence)
